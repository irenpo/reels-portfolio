# Видеопортфолио

Локальная адаптивная галерея вертикальных и горизонтальных рилс.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

После `npm run build` файл `dist/index.html` можно открыть двойным кликом — сервер не требуется.

Медицинское портфолио собирается отдельно в `dist/medical/index.html` и публикуется по адресу `/medical/`.

## Как заменить демонстрационный контент

1. Положите MP4 в `public/videos`.
2. Запустите `npm run posters` — WebP-обложки появятся в `public/posters`.
3. Измените профиль и массив `videos` в `src/data.ts`.
4. Для `aspectRatio` используйте, например, `9 / 16` или `16 / 9`.

Название ролика визуально не показывается, но требуется для доступности.
